# OG Sheru Bhai — Production Checklist

## Prompt बनाने से पहले
- [ ] कहानी का beginning, middle और ending तय है
- [ ] कहानी 15-second clips में बाँटी है
- [ ] हर clip का action और dialogue तय है
- [ ] Character reference image तैयार है
- [ ] Aspect ratio तय है

## AI video generation
- [ ] पहले छोटा test clip बनाया
- [ ] Credits और generation settings जाँचीं
- [ ] जहाँ संभव हो reference image इस्तेमाल की
- [ ] हर clip का output देखकर आगे बढ़े

## Editing और upload
- [ ] Clips सही क्रम में जोड़े
- [ ] Voice और lip-sync जाँची
- [ ] Sound effects और music का level ठीक किया
- [ ] Unwanted gaps और glitches हटाए
- [ ] Final export मोबाइल पर देखा
- [ ] YouTube title, description और thumbnail तैयार किए
