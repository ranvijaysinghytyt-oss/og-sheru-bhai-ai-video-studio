# OG Sheru Bhai — AI Video Studio

यह repository **OG Sheru Bhai** YouTube channel के AI-video content को व्यवस्थित रखने के लिए है।

## यहाँ क्या मिलेगा?
- कहानी और वीडियो आइडिया
- 15-second clips के लिए reusable prompts
- Character और visual continuity notes
- YouTube titles, descriptions और hashtags
- Thumbnail concepts और upload checklist

## काम करने का तरीका
1. `ideas/VIDEO_IDEAS.md` में से आइडिया चुनें।
2. `templates/VIDEO_PROMPT_TEMPLATE.md` भरकर clips के prompts बनाएँ।
3. हर clip में character, कपड़े, आवाज़ और location की continuity रखें।
4. वीडियो तैयार होने पर `templates/YOUTUBE_UPLOAD_TEMPLATE.md` भरें।
5. Publish से पहले पूरी वीडियो देखकर quality जाँचें।

## ज़रूरी सावधानियाँ
- कहानी और संवाद मौलिक रखें।
- AI tool में prompt डालने से पहले duration, aspect ratio और reference-image विकल्प जाँचें।
- Credits खर्च करने से पहले छोटा test clip बनाएँ।
- आवाज़, lip-sync, subtitles और export quality जाँचें।

## Folders
- `ideas/` — वीडियो आइडिया
- `templates/` — reusable templates
- `workflow/` — production checklist
